# E-Commerce Backend

A modern RESTful API for an E-Commerce application built with ASP.NET Core.

## Technologies

- ASP.NET Core 10
- Entity Framework Core
- SQL Server
- ASP.NET Identity
- JWT Authentication
- Swagger
- AutoMapper

## Features

- User Registration & Login
- JWT Authentication
- Product Management
- Categories
- Shopping Cart
- Orders
- Role-Based Authorization
- Image Upload
